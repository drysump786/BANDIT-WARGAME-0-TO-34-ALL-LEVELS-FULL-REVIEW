*/ ROT13 ciphers,https://en.wikipedia.org/wiki/ROT13/

THE LOGIC OF THIS COMMAND IS AS FOLLOWS:(keep  this tricky syntax in mind)
`tr '[A-Za-z]' '[N-ZA-Mn-za-m]'` : the first arg of tr describes the input pattern. Registers all characters lower and upper case. The second arg describes the output pattern. In this case, substitute (transliterate)

'A' = 'N' (it means A gets coded to N)

'B' = 'O' (it means B gets coded to O and so on)

'C' = 'P'

... = ...

'L' = 'Z'

here, we reached z, so we "go back to A".This is what is meant by ROT13 , we rotate back to beginning.  

'M' = 'A'

'N' = 'B'

... = ...  #The letters in small get coded accordingly.

```bash
bandit11@bandit:~$ ls -a
.  ..  .bash_logout  .bashrc  .profile  data.txt

bandit11@bandit:~$ cat data.txt | tr "A-Za-z" "N-ZA-Mn-za-m"
```
